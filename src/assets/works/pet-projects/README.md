# Как добавить работу сюда

1. Add file → Upload files → перетащите картинку → Commit changes.
2. Название файла становится заголовком на сайте — называйте описательно,
   например `mtg-fanart-therizinosaurus.png`.

Эта папка — для пет-проектов: фан-арт, стади, личные эксперименты (MTG-карты,
изекай-иллюстрации и т.д.). Для Plarium и ранних работ — соседние папки.

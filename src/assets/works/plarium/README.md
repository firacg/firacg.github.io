# Как добавить работу сюда

1. Откройте эту папку на github.com (вы уже здесь, если читаете это в браузере).
2. Нажмите **Add file → Upload files** справа сверху.
3. Перетащите картинку (jpg/png/webp) и нажмите **Commit changes**.
4. Через 1–2 минуты после публикации сайта работа появится в разделе «Plarium».

**Название файла становится заголовком на сайте** — называйте описательно,
например `throne-siege-tower.jpg`, а не `IMG_2381.jpg`.

Эта папка — для работ по Throne: Kingdom at War и Vikings: War of Clans.
Для остального смотрите соседние папки `early` и `pet-projects`.
